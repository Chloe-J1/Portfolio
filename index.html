Genetic Algorithm

Description

Genetic algorithms are generally used to solve optimization problems, but I wanted to see if this could be used for game balancing since this could save a lot of time when adding new features to a game. I researched this by recreating an abstract version of the minecraft combat system and running the genetic algorithm on it.

Zombie Survivor AI

Description

In this zombie survival game the survivor agent is capable of making its decisions on its own, based on the situation he is in. I made custom tasks which specify what the survivor should do, the transitioning between which task is being executed is handled with a behavior tree. Moving the survivor is done with steering behaviors: seek, flee, avoid and priority steering.
