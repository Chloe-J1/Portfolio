Clutch Patch

Description

This project was created for L'Oréal Garnier to help them step into the gaming world. The game is designed for Twitch streamers, allowing them to engage their audience through chat messages that influence the gameplay. Our biggest challenge was finding a way to connect Unity with the live chat, eventually we bridged this gap with the Unity Twitch Chat IRC.

My contributions

  • Integrate the Twitch API
  • Twitch events
  • Quest system
